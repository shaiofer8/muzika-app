# מי מזהה את השיר? — כלי משחק קבוצתי

אתר סטטי חד-עמודי לזיהוי שירים: לחיצה על "שיר הבא" שולפת שיר רנדומלי מהמאגר (בלי לחזור מיידית על השיר הקודם), מציגה שם שיר + אומן + שנה, ומנגנת אותו ישירות מ-YouTube בתוך העמוד. משמש כתחליף ל-DJ ידני במשחק ניחוש קבוצתי — ניקוד הקבוצות מנוהל ידנית (נייר/לוח), לא באתר.

## מבנה הפרויקט

- `index.html` — מבנה העמוד
- `style.css` — עיצוב (וינטג'/תקליטים)
- `songs.js` — **מאגר השירים** (ראה למטה)
- `app.js` — לוגיקת הבחירה הרנדומלית והטמעת הנגן

## איך מחליפים את רשימת השירים

`songs.js` מכיל כרגע רשימת דוגמה (~14 שירים) לבדיקה מבנית בלבד. כדי להטעין את הרשימה האמיתית (כ-500 שירים):

1. פתחו את `songs.js`.
2. החליפו את מערך `window.SONGS` ברשימה המלאה, כשכל שיר הוא אובייקט בפורמט:

   ```js
   { title: "שם השיר", artist: "שם האומן", year: 1986, youtubeId: "" }
   ```

   - `title`, `artist`, `year` — חובה.
   - `youtubeId` — **אופציונלי**. אם ידוע מזהה סרטון YouTube מדויק לשיר (11 התווים שאחרי `v=` בקישור), הכניסו אותו כאן והאתר ינגן בדיוק את הסרטון הזה. אם משאירים ריק (`""`), האתר יבצע חיפוש אוטומטי ב-YouTube לפי "אומן שם-שיר".

3. שמרו וזהו — אין build step, אין תלויות. `index.html` נטען ישירות.

## מגבלות ידועות

- **ניגון אוטומטי:** בחלק מהדפדפנים (בעיקר בנייד) הדפדפן עלול לחסום ניגון אוטומטי עם קול. אם זה קורה, פשוט לוחצים על כפתור ההפעלה בתוך נגן היוטיוב עצמו.
- **חזרה על שירים:** כפתור "שיר הבא" מונע רק חזרה *מיידית* על השיר הרגעי — לא shuffle מלא. באוסף של מאות שירים ייתכן ששיר יחזור שוב תוך כמה לחיצות.
- **שורות פגומות:** שורה ב-`songs.js` בלי `title` או `artist` תיפסל אוטומטית ולא תופיע במאגר (לא תפיל את האתר).

## הרצה מקומית

פותחים את `index.html` בדפדפן, או מריצים שרת סטטי:

```
npx serve .
```
